# Describe Your Ex in One Word

One word that sums up an ex: **expired** — past the sell-by date, no longer
fit for consumption, and everyone who has had one knows the feeling at a
glance.

## How it is made

`main.py` is a small Python program using only the standard library. It
writes the single word to `/output/entry.txt` (the location the judge reads
at grade time), with the file mode set to 644 so the grader can read it.
For local verification, set `ENTRY_OUTPUT_DIR` to write it somewhere else
instead, e.g. `ENTRY_OUTPUT_DIR=. python3 main.py`.

## Run it

```sh
python3 main.py
```

Writes the one-word entry to `/output/entry.txt` (or
`$ENTRY_OUTPUT_DIR/entry.txt` when set). Python standard library only.
